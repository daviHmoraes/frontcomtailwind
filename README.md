# TRAVELYA

Front-End desenvolvido como prova de Programação Front-End, foi adaptado a versão mobile para TailWind como atividade. e também foi adicionado o arquivo .js.
Código passado para o TailWind porém o CSS inicial ainda está comentado no arquivo.

## Funcionalidade

- Avaliações dos usuários interativa, ao clicar nos dots abaixo da avaliação você navega entre elas.

## Tecnologias

- TailWind;
- CSS;
- HTML;
- JavaScript.

## Como executar

Para executar o projeto basta abrir um diretório e executar:

    git clone https://github.com/davihmoraes/frontcomtailwind.git

Depois, basta adicionar a extensão Live Server ao seu VS Code e executá-la.
Após executar o Live Server, acesse:

    http://localhost:5500/index.html
